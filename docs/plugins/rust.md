# Plugins in Rust

You can write a plugin in Rust. It is compiled to **WebAssembly** and runs inside the widget's iframe, exactly like a JavaScript plugin:

- same sandbox (no disk, no network, no programs outside the SDK)
- same [manifest](manifest.md), same [permissions](permissions.md), same audit log
- same installation, integrity check and debugging tools

The Rust code calls Tessera through the `tessera-plugin` crate, which wraps the JavaScript SDK (`window.tessera`). JavaScript plugins keep working as before: the two kinds can be installed side by side.

Full example: [`examples/rust/hello-rust`](../../examples/rust/hello-rust) (source) builds into [`examples/plugins/hello-rust`](../../examples/plugins/hello-rust) (the plugin folder).

## What you need

```bash
rustup target add wasm32-unknown-unknown
```

```bash
cargo install wasm-bindgen-cli --version 0.2.129
```

The `wasm-bindgen-cli` version must match the `wasm-bindgen` version of the crate (`=0.2.129`).

## Start a project

```bash
npm run plugin -- new my-plugin --rust
```

This creates a ready-to-build project (see [Packaging](packaging.md) for the `tessera-plugin` tool):

```
my-plugin/
  tessera-plugin.json   says where the two parts are
  plugin/               the plugin folder that you install
    manifest.json
    widget.html
    widget.js           3 lines that load the WebAssembly module
    widget.css
    pkg/                generated by tessera-plugin build
  rust/                 the crate (Cargo.toml, src/lib.rs)
```

The crate stays **outside** the plugin folder: the plugin folder is copied and hashed at install time, and a `target/` folder would quickly pass the 50 MB limit.

## The crate

```toml
[package]
name = "my-plugin"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
tessera-plugin = { path = "path/to/Tessera/packages/plugin-sdk-rust" }
wasm-bindgen = "=0.2.129"
serde = { version = "1", features = ["derive"] }
web-sys = { version = "0.3", features = ["Document", "Element", "HtmlElement", "Window", "Event", "EventTarget"] }

[profile.release]
opt-level = "s"
lto = true
```

`web-sys` is only needed if your Rust code touches the page (buttons, text). You can also keep the page in JavaScript and call Rust functions exported with `#[wasm_bindgen]`.

```rust
use serde::{Deserialize, Serialize};
use tessera_plugin::wasm_bindgen::prelude::wasm_bindgen;
use tessera_plugin::{files, spawn_local, ui, widget};

#[derive(Default, Serialize, Deserialize)]
struct State {
    #[serde(default)]
    count: i64,
}

#[wasm_bindgen(start)]
pub fn start() {
    spawn_local(async {
        if let Err(error) = run().await {
            let _ = ui::toast(ui::Toast::Error, error.message()).await;
        }
    });
}

async fn run() -> tessera_plugin::Result<()> {
    tessera_plugin::ready().await?;
    let mut state: State = widget::get_state().await.unwrap_or_default();
    state.count += 1;
    widget::set_state(&state).await?;
    let entries = files::project().list("sources").await?;
    ui::toast(ui::Toast::Success, &format!("{} entries in sources/", entries.len())).await
}
```

## The page

`widget.html` loads the SDK first, then your module:

```html
<!doctype html>
<html>
  <head>
    <meta charset="utf-8" />
    <script src="/__tessera/sdk.js"></script>
    <link rel="stylesheet" href="widget.css" />
  </head>
  <body>
    <main id="app"></main>
    <script type="module" src="widget.js"></script>
  </body>
</html>
```

`widget.js`:

```js
import init from './pkg/my_plugin.js';

init().catch((error) => console.error(error));
```

## Build and pack

```bash
npm run plugin -- build my-plugin
```

`build` runs `cargo build --release --target wasm32-unknown-unknown`, then `wasm-bindgen --target web` into `plugin/pkg/`. Install `plugin/` as a **Development link** and rebuild after each change: the widget's **Reload** button (plugin lab) picks up the new `.wasm`.

To share it:

```bash
npm run plugin -- pack my-plugin
```

It builds, checks and writes `<id>-<version>.tessera-plugin`. The example builds the same way: `npm run plugin -- pack examples/rust/hello-rust`.

Without the tool, the two commands are:

```bash
cargo build --release --target wasm32-unknown-unknown
```

```bash
wasm-bindgen --target web --no-typescript --out-dir ../plugin/pkg target/wasm32-unknown-unknown/release/my_plugin.wasm
```

## The API

Every function is `async` and returns `tessera_plugin::Result<T>`. Errors carry the same messages as in JavaScript (`permission denied: net`, `outside scope`…); `error.is_permission_denied()` tells you if the user refused a permission.

| Rust | JavaScript | Permission |
| --- | --- | --- |
| `tessera_plugin::ready()` | `tessera.ready` | |
| `tessera_plugin::on::<T>(event, f)` | `tessera.on(event, f)` | |
| `ui::toast(Toast::Success, text)` | `tessera.ui.toast` | |
| `widget::get_state::<T>()`, `widget::set_state(&state)` | `tessera.widget.getState/setState` | |
| `project::info()` | `tessera.project.info` | |
| `settings::get::<T>(key)`, `settings::all()`, `settings::set`, `settings::reset`, `settings::on_change` | `tessera.settings.*` | |
| `files::project().list/read_text/write_text/mkdir/remove/rename/read_bytes/write_bytes` | `tessera.files.*` | `fs.project.read` / `fs.project.write` |
| `files::private().…` | `tessera.files.private.*` | `fs.project.write` |
| `files::watch(f)` | `tessera.files.watch` | `fs.project.read` |
| `external::pick()`, `external::info()`, `external::folder().…` | `tessera.external.*` | `fs.external` |
| `net::fetch(url, &FetchOptions)`, `net::get_url(url)` | `tessera.net.fetch` | `net` |
| `secrets::get/set/delete/keys` | `tessera.secrets.*` | `secrets` |
| `exec::run/run_system/pick_system/system_info` | `tessera.exec.*` | `exec` / `exec.system` |
| `discord::set_activity(Some(&Activity))` | `tessera.discord.setActivity` | `discord.rpc` |
| `clipboard::write_text` | `tessera.clipboard.writeText` | `clipboard.write` |
| `notify::show(title, body)` | `tessera.notify.show` | `notify.system` |
| `shell::open_url`, `shell::reveal(path, scope)` | `tessera.shell.*` | `open.external` |
| `projects::list()` | `tessera.projects.list` | `projects.list` |

`read_bytes` and `write_bytes` take and return `Vec<u8>` / `&[u8]`. Events return a `Subscription`: it stops listening when dropped, so keep it, or call `.keep()` to listen for the life of the widget.

For the details of each call (limits, errors, return values), see [SDK](sdk.md): the Rust functions follow it one to one.

## Good to know

- The SDK script must be loaded **before** your module, or every call fails with "the Tessera SDK is not loaded".
- Panics end up in the widget's console as `unreachable` errors. Return `Result` and show errors with `ui::toast` instead.
- A release build of the example weighs about 140 KB. Keep `opt-level = "s"` and `lto = true`.
- Heavy work still runs on the widget's thread: split long loops with `.await` points so the widget keeps answering Tessera's pings (see [Lifecycle](lifecycle.md)).
